# Nepal Travel — Discover Hidden Natural Retreats

A PHP and MySQL web application for discovering travel destinations across Nepal. It helps visitors browse places, plan trips, estimate travel costs, create an account with email verification, and manage their profile. Administrators can manage destination data.

## Features

- Browse Nepal travel destinations and view their details.
- Plan a trip with route, vehicle, and estimated-cost information.
- Register and log in securely with PHP sessions.
- Verify new registrations using a six-digit, time-limited email OTP.
- Resend OTPs and limit verification attempts.
- View and update a user profile.
- Admin pages and APIs for managing travel data.
- Upload and serve destination images.

## Technology

- PHP 8+
- MySQL / MariaDB (via XAMPP)
- HTML, CSS, and vanilla JavaScript
- PHPMailer for SMTP email delivery
- Composer for PHP dependency management

## Requirements

- PHP 8 or later
- Composer
- A Gmail account with a Google App Password, or another SMTP provider

## Installation

1. Clone the repository into XAMPP's `htdocs` folder.

   ```powershell
   git clone <repository-url> C:\xampp\htdocs\Group-05
   cd C:\xampp\htdocs\Group-05
   ```

2. Install PHP dependencies.

   ```powershell
   composer install
   ```

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Configure SMTP credentials by creating `PHP/mail_config.local.php`:

   ```php
   <?php

   return [
       'host' => 'smtp.gmail.com',
       'port' => 587,
       'username' => 'your-email@gmail.com',
       'password' => 'your-google-app-password',
       'from_email' => 'your-email@gmail.com',
       'from_name' => 'Nepal Travel',
   ];
   ```

   For Gmail, use a Google App Password—not your normal Gmail password. You may instead supply the `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`, and `SMTP_FROM_NAME` environment variables.

5. Open the application:

   ```text
   http://localhost/Group-05/public/HTML/index.html
   ```

The app connects to the local `college_project` database. Its PHP database bootstrap creates the database and required tables when the application is first used.

## Email OTP flow

When a visitor registers, the application generates a cryptographically random six-digit code, stores only its password hash in `otp_verifications`, and sends the code through SMTP. Codes expire after ten minutes and have a maximum number of verification attempts.

If OTP email is not sent, first run:

```powershell
composer install
```

Then confirm that `PHP/mail_config.local.php` exists and contains valid SMTP credentials. Check the Apache error log at `C:\xampp\apache\logs\error.log` for delivery errors.

## Security and Git


Do not commit these files or directories:

- `vendor/` — generated by Composer
- `PHP/mail_config.local.php` — contains SMTP credentials
- `uploads/` — runtime uploaded content

The repository's `.gitignore` already excludes these private or generated items. If an SMTP password was ever committed or shared, revoke and replace it immediately.
